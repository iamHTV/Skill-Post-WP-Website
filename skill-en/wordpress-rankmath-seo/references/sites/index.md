# Site profiles

This public skill has no real website profile or default site. Follow [setup](../site-setup.md) to create/select a private local profile. Real records live under the user's chosen PRIVATE_ROOT/references/sites/ and are shared by all three skills.

- [Profile schema](template.md)
- [Fictional website example](example.md)

PRIVATE_ROOT is a replaceable path placeholder, not a hard-coded directory. Ask which private root/profile to use if unknown. List only keys/URLs as needed, never env values. Configuration does not authorize publication or optional integrations.
