# Hồ sơ website

Skill public không chứa hồ sơ website thật hoặc website mặc định. Theo [setup](../site-setup.md) để tạo/chọn hồ sơ riêng. Hồ sơ thật nằm trong PRIVATE_ROOT/references/sites/ do người dùng chọn, dùng chung cho cả ba skill.

- [Định dạng hồ sơ](template.md)
- [Website giả định](example.md)

PRIVATE_ROOT là chỗ thay đường dẫn, không phải thư mục cố định. Chưa biết thì hỏi thư mục/hồ sơ cần dùng. Chỉ liệt kê key/URL khi cần, không in giá trị .env. Hồ sơ cấu hình không tự cho phép xuất bản hoặc dùng tích hợp tùy chọn.
